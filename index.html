Kebijakan Privasi — Social Content Studio

Terakhir diperbarui: 21 November 2026

Pengelola

Social Content Studio dikelola oleh Yeezee Teknologi Indonesia. Pertanyaan atau permintaan terkait data dapat dikirim ke alghifahrizikri@gmail.com.

Data yang diproses

Aplikasi memproses (1) ID dan username akun Instagram Professional serta token akses yang diterima melalui login Meta; dan (2) informasi draf yang Anda masukkan, seperti brand, produk, platform, audiens, isi konten, caption, status alur kerja, dan waktu pembuatan atau perubahan.

Tujuan penggunaan

Data akun digunakan untuk menghubungkan akun Instagram dan menampilkan status serta profil akun. Data draf digunakan untuk menyimpan dan meninjau konten di workspace lokal. Fitur publikasi belum tersedia; aplikasi ini tidak mengunggah draf ke Instagram.

Penyimpanan dan masa simpan

Token dan draf disimpan sebagai file JSON pada perangkat operator aplikasi. Aplikasi tidak mengenkripsi file tersebut; perlindungan bergantung pada keamanan perangkat dan akses sistem operasi. Token disimpan sampai koneksi diputus atau file lokal dihapus. Draf tetap tersimpan sampai operator menghapus file data/posts.json.

Penggunaan layanan pihak ketiga

Login dan permintaan profil akun berkomunikasi dengan Meta/Instagram dan tunduk pada kebijakan privasi Meta. Saat tunnel Cloudflare sementara digunakan untuk callback OAuth, permintaan callback melewati layanan Cloudflare. Halaman kebijakan ini di-host oleh GitHub Pages; GitHub dapat memproses data teknis kunjungan ke halaman tersebut. Aplikasi tidak menjual data atau memakai analitik maupun iklan tertanam.

Keamanan dan akses

Ini adalah prototipe lokal satu operator tanpa login aplikasi dan tanpa enkripsi penyimpanan. Saat tunnel publik aktif, siapa pun yang mengetahui alamatnya dapat mencoba mengakses aplikasi. Tunnel sebaiknya dihentikan segera setelah pengujian OAuth selesai. Jangan gunakan aplikasi ini sebagai layanan publik atau produksi.

Penghapusan dan pilihan Anda

Gunakan Putuskan akun untuk menghapus token lokal. Untuk menghapus draf, operator menghapus file data/posts.json. Anda juga dapat mencabut izin aplikasi melalui pengaturan akun Meta. Permintaan bantuan terkait data dapat dikirim ke kontak pengelola di atas.
